Overall System Architecture
Offline Mapping / 建图阶段
Input
Monocular RGB Sequence (RealSense D456, 848×480)
ORB-SLAM3 trajectory · Camera matrix K
▼
① ROI Annotation & Line Extraction
LSD line detector → 4 boundary lines of road sign
process_sequence_with_cached_rois()
▼
② Corner & Center Computation
Line intersections → {C₁, C₂, C₃, C₄} + Pcenter
calculate_rectangle_center()
▼
③ Looming Depth RecoveryCORE
Temporal expansion → absolute metric depth
calculate_pure_looming_Z_v2()
▼
④ Plane Parameter Estimation
Back-project corners → fit plane → n (normal), d (distance)
estimate_plane_from_corners()
▼
Output
Sign Metric Pose TWS ∈ SE(3)
→ Semantic Map Database
➡
Online Relocalization / 重定位阶段
Input
New Traversal RGB · Pre-built Sign Map
▼
⑤ Road Sign Re-identification
YOLO detection → feature retrieval → sign matching
▼
⑥ Corner & Center Extraction
LSD line detection → 4 corners + center point
extract_four_lines_from_real_image()
▼
⑦ LoFTR Feature Matching
Dense 2D-2D correspondences + RANSAC filtering
match_images_with_loftr_roi() · Kornia LoFTR
▼
⑧ Homography Decomposition
Decompose H → up to 4 solutions {R, tn, n}
cv2.decomposeHomographyMat(H, K)
▼
⑨ Metric Scale InjectionCORE
Looming depth resolves scale ambiguity → metric translation
▼
⑩ 3D Geometric Verification
Orthogonality check → select best solution k*
evaluate_orthogonality() → εortho
▼
Output
Metric Relative Pose {R12, t̃12}
→ Absolute pose constraint → SLAM drift correction
